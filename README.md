# ParkCinema Interactive Venue Ticketing

A front-end ticket-selection site for the ParkCinema IMAX hall, built with plain HTML, CSS and JavaScript for the Web & Mobile I course. Users explore the seat map, click a seat to inspect its details and price, and add it to a cart that is saved in localStorage.

- **Venue:** 10 rows and 281 seats, generated
- **Price zones:** Front (rows 1–2) $8, Standard (rows 3–5) $12, Premium (rows 6–8) $16, Back (rows 9–10) $10
- **Map navigation:** zoom, move and reset buttons, plus mouse-wheel zoom and click-and-drag panning

To run it, open index.html in a browser; no build step or server is needed.
